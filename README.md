# Sistema de Gestão e Entrega Inteligente de Medicamentos

## Sobre o Projeto

Este projeto foi desenvolvido como parte do Projeto Integrado Multidisciplinar (PIM III) do curso de Análise e Desenvolvimento de Sistemas.

A proposta consiste na criação de um sistema web integrado para otimizar a gestão e distribuição de medicamentos, garantindo mais eficiência, controle e acessibilidade no processo logístico.

---

## Objetivo

Desenvolver uma solução tecnológica capaz de:

- Controlar estoque de medicamentos  
- Monitorar datas de validade  
- Gerenciar pedidos e entregas  
- Melhorar a eficiência logística  
- Reduzir perdas e atrasos  

---

## Contexto do Negócio

**Empresa fictícia:** MedFlow Solutions  

- Missão: Otimizar a gestão de medicamentos com tecnologia  
- Visão: Ser referência em soluções digitais para saúde  
- Valores: Inovação, eficiência e acessibilidade
